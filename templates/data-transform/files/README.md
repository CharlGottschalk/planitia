# {{name}}

An MCP server (stdio) that converts CSV to JSON and back. Generated by planitia from the
`data-transform` template.

## Setup

```sh
npm install
npm run build
npm test        # smoke test: starts the server, lists tools, calls them
```

The CSV code is in `src/csv.ts` (no CSV dependency). Add your own transforms as tools in
`src/index.ts`.

## Tools

Both tools are read-only (`readOnlyHint: true`, `destructiveHint: false`). They only transform
the text they are given and never touch files or the network.

### `csv_to_json`

Parses CSV per RFC 4180: quoted fields may contain the delimiter, `""` (an escaped quote) and
newlines. CRLF or LF line endings and a leading BOM are accepted. Returns `{ "rows": [...] }`.
All values are strings, with no type guessing.

| Input | Type | Description |
|-------|------|-------------|
| `csv` | string | The CSV text |
| `delimiter` | string, optional | One character, default `,` |
| `header` | boolean, optional | Default `true`: first row = column names, rows are objects. `false`: rows are arrays |

Malformed CSV returns an `INVALID_CSV: row N: ...` error result. That covers an unterminated
or stray quote, text after a closing quote, a row with the wrong number of fields (header mode),
and a duplicate column name.

### `json_to_csv`

Formats rows as CSV and returns `{ "csv": "..." }`. Lines end with `\n`.

| Input | Type | Description |
|-------|------|-------------|
| `rows` | array | Flat objects (a header row is written from every key, in first-seen order) or arrays (no header) |
| `delimiter` | string, optional | One character, default `,` |

Values may be strings, numbers, booleans or `null` (an empty field). Nested objects are
rejected. Fields that contain the delimiter, a quote or a newline are quoted.

## Guardrails

- **Input validation:** every tool's inputs are checked with zod before it runs. Bad input
  returns an error result (`isError: true`), and the server keeps running.
- **Errors:** failures come back as error results with a code prefix: `TIMEOUT`,
  `RATE_LIMITED`, `INVALID_CSV` or `TOOL_ERROR`.
- **Logging:** JSON lines on stderr only. stdout carries the MCP protocol.
- **Timeout:** each call is limited to `TOOL_TIMEOUT_MS` (default {{timeoutMs}} ms).
  Parsing is synchronous and linear in the input size, so a very large input keeps the
  server busy until it finishes.
- **Rate limit:** at most `RATE_LIMIT_PER_MINUTE` calls per minute across all tools
  (default {{rateLimitPerMinute}}; 0 = off).
- **Cache:** read-only results are cached in memory for `CACHE_TTL_SECONDS`
  (default {{cacheTtlSeconds}}; 0 = off).
- **No secrets:** this server needs no credentials.
- **Spreadsheet formulas:** `json_to_csv` does not rewrite values. A value that starts with
  `=`, `+`, `-` or `@` may run as a formula if the CSV is opened in a spreadsheet.

## Configuration

| Env var | Default | Meaning |
|---------|---------|---------|
| `TOOL_TIMEOUT_MS` | {{timeoutMs}} | Per-call timeout |
| `RATE_LIMIT_PER_MINUTE` | {{rateLimitPerMinute}} | Max calls per minute, 0 = off |
| `CACHE_TTL_SECONDS` | {{cacheTtlSeconds}} | Result cache lifetime, 0 = off |

## Register with an MCP client

Build first, then use the absolute path to `dist/src/index.js`.

**Claude Code**

```sh
claude mcp add {{name}} -- node "$(pwd)/dist/src/index.js"
claude mcp list   # should show {{name}} as connected
```

Add `--scope project` to share the entry through `.mcp.json` (Claude Code asks you to approve it
on the next start), or `-e KEY=value` to set env vars.

**Codex**

```sh
codex mcp add {{name}} -- node "$(pwd)/dist/src/index.js"
```

Or add this to `~/.codex/config.toml`:

```toml
[mcp_servers.{{name|json}}]
command = "node"
args = ["/absolute/path/to/{{name}}/dist/src/index.js"]
```

**Cursor**

Add this to `.cursor/mcp.json` (project) or `~/.cursor/mcp.json` (global):

```json
{
  "mcpServers": {
    {{name|json}}: {
      "command": "node",
      "args": ["/absolute/path/to/{{name}}/dist/src/index.js"]
    }
  }
}
```
